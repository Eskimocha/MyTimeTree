# App Store Connect — 隐私营养标签填写说明

在 App Store Connect → App 隐私 → **开始** / **编辑** 中按下列选择（对应 MyTimeTree **1.0.0** 离线版）。

> 若你后续加入统计、崩溃上报、登录服务器等，必须回来改这份声明。

---

## 1. 是否收集数据？

选：**是，我们会从此 App 收集数据**  
（原因：应用会在设备上处理孩子昵称、流水等「用户内容」；即使不上传到你的服务器，Apple 仍要求如实申报「收集」——含设备端收集后用于 App 功能的数据。若你更严格解读为「仅设备且不同步到开发者」也可对照 [Apple 文档](https://developer.apple.com/app-store/app-privacy-details/) 再确认；对「可选 iCloud」建议按「会收集用户内容」申报更稳妥。）

---

## 2. 数据类型勾选建议

### 建议勾选

| Apple 类别 | 勾选？ | 说明 |
|------------|--------|------|
| **联系信息** | 否 | 不收集邮箱/电话（除非你以后做账号） |
| **健康与健身** | 否 | — |
| **财务信息** | 可选「其他财务信息」 | 时间「分」是虚拟记账，不是真实支付；多数情况勾 **用户内容 → 其他用户内容** 即可，不必当真实银行卡财务 |
| **位置** | 否 | — |
| **敏感信息** | 否 | — |
| **通讯** | 否 | — |
| **用户内容** | **是** | **其他用户内容**：昵称、流水、设置、安全问题答案等 |
| **浏览历史 / 搜索历史** | 否 | — |
| **标识符** | 否 | 无广告标识、无账号 ID |
| **购买项目** | 否 | 无 IAP（当前） |
| **使用数据** | 否 | 无分析 SDK |
| **诊断** | 否 | 无崩溃上报 SDK（系统自带不由你收集） |
| **周边环境** | 否 | — |
| **身体 / 运动** | 否 | — |
| **其他数据** | 一般否 | — |

### 「用户内容 → 其他用户内容」用途

- [x] **App 功能**  
- [ ] 分析（不勾）  
- [ ] 产品个性化（不勾）  
- [ ] 广告（不勾）  
- [ ] 其他目的（不勾，除非有）

### 关联与追踪

对「其他用户内容」：

- **是否关联到用户身份？** → **是，关联到用户的身份**（数据属于该设备上的家长/孩子档案；有本地账户概念）  
  - 若 Apple 问卷选项是「关联到用户」/「不关联」：选 **关联** 更贴近「有孩子账户与流水」。  
- **是否用于追踪？** → **否**

### iCloud

同步到用户自己的 iCloud **不算**你把数据卖给第三方；仍属用户内容用于 App 功能。无需单独勾「开发者服务器」。

## 3. 权限与用途文案（Info.plist，已写好）

| Key | 中文用途说明 |
|-----|----------------|
| Face ID | 使用 Face ID 快速解锁 MyTimeTree，保护孩子的时间资产记录。 |
| 添加照片 | 将当前页长图保存到相册，方便你用微信等方式分享孩子的时间树。 |

分享路径：**不**自动写入相册；仅当用户在系统面板点「存储图像」时由系统写入。

---

## 4. 出口合规

Info.plist 已设 `ITSAppUsesNonExemptEncryption = false`（仅使用系统标准加密，如 HTTPS/iCloud/系统钥匙链类能力）。首次上传若仍弹出问卷，选「App 未使用非豁免加密」即可。
