## 应用名称

`MyTimeTree`

（若重名冲突，可用：`MyTimeTree - 时间树`）

## 副标题（≤30 字，含标点）

```
每天存一点时间，种一棵大树
```

备选：

```
亲子时间资产与成长树
```

## 宣传文本（≤170 字，可随时改、无需审版本）

```
把「时间」变成看得见的成长树：存入、支出、借用都记在本机，家长锁保护，可选 iCloud 同步。适合和孩子一起养成记账与延迟满足的习惯。
```

## 描述（详情）

```
MyTimeTree 帮家长用「时间分」记录孩子的日常：存入奖励、支出、借用，并长成一棵会升级的树，挂上星星、太阳等挂件。

【适合谁】
• 想和孩子一起建立时间/奖励规则的家长
• 重视隐私、希望数据留在自己手机里的家庭

【主要功能】
• 离线记账：资产、负债、利息与流水一目了然
• 成长树与挂件：净资产驱动阶段变化，成就看得见
• 家长锁：密码 + 可选 Face ID；安全问题可找回密码
• 多孩子账户：切换管理更方便
• 可选 iCloud 整库同步与恢复，换机不丢树
• 一键分享长图，用系统面板发给家人（不自动存相册）

【隐私】
无强制注册，无广告追踪 SDK。数据在本机；若你开启 iCloud，则同步到你自己的 iCloud。详见应用内链接的隐私政策。

继续种树吧——每天存一点时间，未来还你一棵大树。
```
