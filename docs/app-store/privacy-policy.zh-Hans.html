MyTimeTree 隐私政策

生效日期：2026-09-11 · 适用于 iOS 应用「MyTimeTree」

欢迎使用 MyTimeTree（以下简称「本应用」）。本应用由开发者提供，用于帮助家长记录孩子的时间资产与成长树。我们重视您与孩子的隐私。请仔细阅读本政策；使用本应用即表示您知悉并同意本政策所述做法。

1. 我们是谁

本应用为完全离线的工具：核心数据保存在您的设备本地，不强制注册账号，也不依赖我们自建的用户数据服务器。

如需就隐私问题联系我们，请发送邮件至：kaiak.fang@gmail.com。

2. 我们收集哪些信息

本应用处理的信息主要用于「App 功能」，包括但不限于：

  • 孩子相关内容：昵称、时间资产/负债与流水、利率与规则设置、挂件与成长阶段等（由您录入或由本应用根据规则计算）。
  • 家长安全信息：家长密码的校验数据（不以明文形式展示）、可选的安全问题与答案（用于忘记密码时重置）、是否启用 Face ID 的偏好。
  • 设备能力相关：为解锁而使用系统 Face ID / 生物识别时，识别过程由 Apple 系统完成，本应用无法读取您的面容或指纹原始数据。
  • 您主动分享的图像：当您使用「分享」功能生成页面长图，并在系统分享面板中选择「存储图像」或分享给其他 App 时，图片由您选择的目标处理。

本应用不会为了广告而收集设备广告标识符，也未集成第三方广告或分析 SDK（以当前公开发布版本为准）。

3. 信息如何存储与同步

  • 本机存储：业务数据保存在您设备上的本地数据库中。
  • 可选 iCloud 同步：若您的设备已登录 iCloud 并启用相关能力，本应用可将整库文件同步到您的 iCloud 容器（标识：iCloud.com.mytimetree.app），以便同 Apple ID 下的设备间备份与恢复。iCloud 的存储与传输由 Apple 按其条款与隐私政策处理。
  • 无强制云账号：您可以不使用 iCloud；此时数据仅留在本机。

4. 我们如何使用信息

上述信息仅用于：

  • 提供时间树记账、展示、设置与家长锁等核心功能；
  • 在您授权下完成 Face ID 解锁、相册写入（仅当您在系统面板中选择保存时）、系统分享；
  • 在您启用时进行 iCloud 整库同步与恢复。

我们不会将上述信息用于追踪您在其他公司 App 与网站中的行为，也不会出售给数据经纪人。

5. 信息共享

除下列情形外，我们不会向第三方出售或出租您的应用内内容：

  • 您主动操作：例如通过系统分享面板发送给微信等应用，或存储到「照片」；
  • Apple 系统服务：Face ID、iCloud、系统分享等，适用 Apple 的隐私政策；
  • 法律要求：在法律法规要求或有权机关依法提出时。

6. 儿童与家长责任

本应用面向家长管理孩子的时间资产记录。孩子相关数据由家长录入与保管。请您：

  • 妥善设置并保管家长密码与安全问题答案；
  • 在共用设备上启用锁屏 / Face ID；
  • 理解「清除本机数据」等操作不可恢复（除非您另有 iCloud 或其他备份）。

7. 权限说明

  • Face ID：用于快速解锁本应用（可选）。
  • 添加照片到相册：仅当您在系统分享流程中选择将图片存入相册时使用；本应用不会在您未选择时自动写入相册。

8. 数据保留与删除

  • 本机数据随您卸载应用或使用应用内「清除本机数据」等功能而删除。
  • iCloud 中的备份文件可由您在本机「从 iCloud 恢复 / 同步」相关操作中覆盖，或在系统「文件 / iCloud」相关界面中按 Apple 提供的方式管理；卸载 App 不一定自动删除 iCloud 中已有文件。

9. 安全

我们采取合理措施保护本地数据（包括家长锁）。但任何电子设备都无法保证绝对安全，请结合系统锁屏、Face ID 与强密码降低风险。

10. 政策更新

我们可能适时更新本政策。更新后会在本页面调整「生效日期」。重大变更时，建议您重新阅读。

11. 联系我们

如对本政策或个人数据处理有疑问，请联系：kaiak.fang@gmail.com。
