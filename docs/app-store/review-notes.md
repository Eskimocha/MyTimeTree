# App Store 审核备注（粘贴到「审核附注」）

把下面整段复制到 App Store Connect → 版本 → **App 审核信息 → 备注**。按需改括号内容。

## 中文版（推荐）

```
【产品说明】
MyTimeTree 是一款面向家长的离线「时间资产」记账工具：用「时间分」记录孩子的存入/支出/借用，并以成长树与挂件可视化。无强制注册、无自建用户服务器。

【如何体验】
1. 打开 App → 为孩子开户（昵称 + 家长密码 + 安全问题/答案）。
2. 主屏可记账；「设置」可改规则；支持 Face ID 解锁（可选）。
3. 「设置 → iCloud 同步」：需真机登录 iCloud，并开启 iCloud 云盘；可「立即同步」或「从 iCloud 恢复」。
4. 主屏分享按钮：生成长图并打开系统分享面板；不会自动写入相册，需用户手动选择「存储图像」才会保存。

【审核账号】
本 App 无云端登录账号。请直接在设备上开户体验。
家长密码示例（若你们预装了演示包）：（无预装则自行设置，例如）1234
安全问题答案：按开户时填写。

【权限】
- Face ID：仅用于解锁 App。
- 照片（添加）：仅当用户在系统分享中选择保存图片时使用。

【隐私】
隐私政策 URL：（https://eskimocha.github.io/MyTimeTree/ ）
数据主要存本机；可选同步至用户自己的 iCloud 容器 iCloud.com.mytimetree.app。

【联系】
开发者邮箱：kaiak.fang@gmail.com
```

## English version（可选，国际审核员）

```
MyTimeTree is an offline parental “time wallet” app: track a child’s time credits with a growing tree metaphor. No mandatory account, no developer-operated user server.

To review: open the app → create a child profile (name + parent password + recovery Q&A) → use Home / Settings. Face ID is optional. iCloud sync requires a signed-in iCloud account with iCloud Drive. Share exports a long image via the system share sheet and does NOT auto-save to Photos unless the reviewer chooses Save Image.

Privacy Policy: https://eskimocha.github.io/MyTimeTree/
Contact: kaiak.fang@gmail.com
```
