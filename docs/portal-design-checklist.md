# MyTimeTree Portal — 设计检查清单（E8.1）

评审对象：家长端移动优先 SPA（浅色儿童主题）

## 必须满足

- [x] **移动优先**：默认视口按手机宽度构图；主操作拇指可达
- [x] **品牌**：首屏可见 **MyTimeTree** 品牌名（非仅导航小字）
- [x] **浅色儿童主题**：日光天空→叶片绿氛围；避免深紫渐变 / 报纸风
- [x] **主屏一屏**：品牌 + 树/余额焦点 + 一句说明 + 支/借/还主 CTA；无仪表盘堆砌
- [x] **账户切换**：最外层账户壳，切换后数据与设置绑定当前孩子
- [x] **首启开户**：无账户时强制 onboarding，不可进入主 Tab
- [x] **进账红 / 支出绿**：流水 Tab 遵循中文财务配色
- [x] **关页提示**：设置草稿 dirty 时 `beforeunload` 提示（对接 persistence）

## 交互分区

| 区域 | 职责 |
|------|------|
| 账户壳 | 选择/切换孩子账户 |
| 主屏 | 资产/负债/树阶段与挂件；支/借/还 |
| 流水 Tab | 分页列表 + 颜色 |
| 设置 Tab | 派发/默认分钟等（利率改动走二次确认后续可接） |
| 分析 Tab | 周/月简报 |

## 动效（至少 2–3 处）

- 主屏树阶段切换淡入
- Tab 切换轻微上浮
- 主按钮按压反馈

## 评审结论

原型路径：`src/mytimetree/static/portal/`（由 FastAPI `/` 提供）
