## 2. IA / 交互变更

### 2.1 记录前引导（相对 IH7/IH9 的升级）

| 现状（初版） | 目标 |
|--------------|------|
| 点「记」后 overlay 才出情绪短句 + 家长话术 | **点「记」之前**，在种子习惯 chip/条旁展示情绪提示 + 家长话术 |
| 情绪路径易写成「大道理」 | 去掉向上抽象的功利/说教句；可向下给「微步骤建议」（非打卡项） |
| 微步骤若不存在 | 新增内容层：微步骤 = 建议，**不进**今日打卡清单 |

**交互草图（主屏 strip）**

```
[记 · 刷牙]  ← chip 主操作仍为一键记
  微步骤建议（可选一行）：先漱口 → 再挤牙膏 …
  情绪提示（短）：口气清新
  家长话术（短）：牙齿保卫战胜利！要不要击个掌？
```

- 空间不够时：默认露出「情绪 + 话术」各一行；微步骤可折叠为「怎样更容易做」展开。
- 点「记」后：仍可保留轻量庆祝（入账分钟 + 可选线下 hint），但**不再把话术/情绪首次曝光放在弹层**。
- 大庆祝（周满 5）仍可走 overlay / 分析复盘（Q9 不变）。

### 2.2 主屏布局

| 项 | 变更 |
|----|------|
| 习惯模块位置 | 移到「支出 / 借用 / 存入」**下方**（按钮组先，习惯条后） |
| 模块高度 | 习惯区块高度**自由可调**（家长拖动手柄或分隔条；持久化到本机 settings/extra_json） |
| 主屏滚动 | **解除一屏锁定**：`#portal` / 主屏纵向可滚，习惯展开后不裁切 |
| 英雄树 | **恢复正常高度**（撤销/修正把 tree hero 压矮的样式），保证阶段图完整可见 |

仍遵守：无第五 Tab；无「兑」按钮（IA-D2 / P-D7）。

### 2.3 流水摘要

| 现状 | 目标 |
|------|------|
| 时间与数量列宽被挤成两行乱版 | **摘要与时间各占一行**；**数量跨两行**合并显示（视觉上数量单元格 `row-span: 2`） |

仅改流水列表呈现，不改 `habit_reward` 语义。

### 2.4 设置 · 好习惯清单

| 现状 | 目标 |
|------|------|
| 「上移 / 下移」按钮 | **拖拽排序**；去掉上移/下移按钮 |
| 启用/自定义/移除/改分钟 | 保留（C-D1） |

### 2.5 分析页

| 现状 | 目标 |
|------|------|
| 「好习惯」块在上、「时间资产」在下 | **对调**：时间资产（周/月趋势）在上；好习惯看板在下 |

## 3. 内容模型

在现有 `docs/v2/content/` 上扩展（C-D2/C-D3 不变：表真源 → build 打入包）。

### 3.1 表与字段（建议）

| 表文件 | 用途 | 相对初版的变化 |
|--------|------|----------------|
| `habit-templates.md` | 可打卡种子 | 保持；`notes` 可链到微步骤组 id |
| **新建** `habit-micro-steps.md` | 微步骤建议（**不可打卡**） | 列：`id`, `habit_slug`, `sort`, `step_text`, `active` |
| `emotion-copy.md` | 情绪路径短句 | **改写规范**：禁止向上说教/功利（如「少后悔」「为未来负责」）；宜具体可感（「口气清新」「被看见」）；可按 slug/category |
| `parent-scripts.md` | 家长话术 | 同样去说教；长度宜适合 **chip 旁一行**（建议 ≤28 字） |
| `offline-celebration-hints.md` | 线下庆祝 | 可仍在记后轻量展示；非主曝光 |
| **新建或扩展** `habit-board-copy.md` | 分析页图例/汇总文案 | 列：`id`, `slot`（legend_intro / month_summary…）, `copy_text`, `active` |

### 3.2 微步骤语义（锁定建议，待 Kai 确认 → 见开放问题 OQ-1）

- 微步骤是**建议**，不出现在今日 strip 的「记」列表，无 `habit_logs`，无分钟兑换。
- 展示时机：**记录该种子习惯之前**（与话术/情绪同级前置）。
- 例：种子「按时上床」← 建议「先放下屏幕」「先去刷牙」「先关灯」。

### 3.3 情绪路径改写原则（Fogg 对齐，供内容 Agent）

- **Motivation**：具体感受，不讲大道理。  
- **Ability**：用微步骤降低难度，而不是道德动员。  
- **Prompt**：话术给家长「当下能说的一句」，不是训诫提纲。
