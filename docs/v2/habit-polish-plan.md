## 3. IA / 交互变更

### 3.1 记前（O2）

```
[记 · 刷牙]  [ⓘ]     ← 种子 chip + 常显提示图标
  └ 展开后分层：
      微习惯：先漱口 · 挤牙膏 …
      家长话术：牙齿保卫战胜利！…
      （激励/小庆祝文案可作展开区一句，记后 overlay 再强调入账）
```

- 默认折叠微习惯与话术；仅图标常显。
- 点「记」后：一般 → 小庆祝 overlay（入账分钟等）；周满大庆祝 → 霸屏蒙版（Q9）。

### 3.2 主屏布局（O3）

| 项 | 变更 |
|----|------|
| 习惯模块位置 | 「支出 / 借用 / 存入」**下方** |
| 主屏滚动 | 纵向可滚，不再锁死一屏 |
| 英雄树 | **恢复原来高度**，完整展示阶段图 |
| ~~习惯区高度可调~~ | **删除**（勿实现底边手柄） |

### 3.3 流水（O4）

摘要与时间各一行；数量跨两行合并显示。

### 3.4 设置（O5）

拖拽排序；去掉上移/下移按钮。微步骤可在设置内按习惯编辑（O1）。

### 3.5 分析（O6）

时间资产在上、好习惯在下；当月点阵 7 天一行；按习惯稳定色；图例 + 可保留文字汇总。

## 4. 内容模型

| 表 | 用途 |
|----|------|
| `habit-templates.md` | 可打卡种子 |
| **`habit-micro-steps.md`** | 默认微步骤（`id`, `habit_slug`, `sort`, `step_text`, `active`） |
| `parent-scripts.md` | 家长话术（chip 旁短句） |
| `emotion-copy.md` | 可收敛为激励/小庆祝短句，或逐步由 micro+script 替代主路径 |
| `offline-celebration-hints.md` | 线下 hint（记后可选） |
| `habit-board-copy.md` | 分析图例/汇总文案 |

**运行时**：默认微步骤自表种子；家长增删改写入本机 SQLite（按 `account_id` + `habit_id`），不覆盖表默认的合并策略：用户自定义优先展示，表行作「恢复默认」来源。
