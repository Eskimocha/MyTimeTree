# 习惯模块 — 可编辑内容表（发版真源）

> Kai / 内容 Agent 在发版前改这些表；App 构建/同步时打入包内。  
> 更好实践 → 改表 → 升版推送（C-D2）。**不做**在线 CMS。

## 表清单

| 文件 | 用途 | 主键 |
|------|------|------|
| `habit-templates.md` | 种子好习惯（标题、分类、默认分钟） | `slug` |
| `habit-micro-steps.md` | 默认微习惯/微步骤（**不可打卡**；家长可在 App 内增删改） | `id` |
| `parent-scripts.md` | 家长话术（按分类或 slug） | `id` |
| `offline-celebration-hints.md` | 线下庆祝动作建议 | `id` |
| `emotion-copy.md` | 激励/短句（可作小庆祝补充） | `id` |
| `habit-board-copy.md` | 分析页图例/汇总文案 | `id` |

## 编辑约定

1. 只改表格行，勿改列名（脚本按表头解析）。  
2. 新增行用新 `slug`/`id`；停用用 `active=0`。  
3. 用户自定义习惯与家长自定义微步骤不进本表（进本机 SQLite）。  
4. 微步骤不是种子习惯：无兑换、不进「记」主列表。  
5. 话术宜短（chip 旁 / 展开层，建议 ≤28 字）；避免说教大道理。

## 与设置 UI

- **清单自定义 / 微步骤编辑 / 拖拽排序** = 用户数据（SQLite + iCloud）。  
- **默认话术 / 默认微步骤 / 看板文案** = 本目录表格，随 App 版本更新。
